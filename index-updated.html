Core Takeaway #1

Analysis begins with the research question and study design —

not with opening SPSS, Stata, or R.

Rapid Review — Study Design Landscape

Emphasize: descriptive cross-sectional studies describe “what/who/where”; analytical designs test “why/is there an association”.

Design → Question It Answers

Design Typical Question Direction of Inquiry Key Output
Cross-sectional (descriptive) How common is X? Snapshot Prevalence
Case-control What’s associated with disease? Outcome → exposure Odds Ratio
Cohort Does exposure predict outcome? Exposure → outcome Risk Ratio / Incidence
RCT / Community trial Does intervention change outcome? Allocated exposure → outcome Risk difference / RR

Ask participants (chat): “Which of these is your dissertation design?” Use responses to tailor emphasis for the rest of the workshop.

✅ Identify-the-Design Check

A resident recruits 300 hypertensive and 300 normotensive adults from a clinic and looks backward at their salt-intake history.

A. Cohort   B. Case-control   C. RCT   D. Cross-sectional

Answer: B — Case-control. Outcome status (hypertensive vs not) is fixed at recruitment; exposure (salt intake) is measured retrospectively.

Commit-reveal-explain. Ask for chat answers before advancing the fragment. Common wrong answer: cross-sectional — clarify that the backward-looking, outcome-anchored sampling is the case-control signature.

Bridge: Design → Variables → Analysis

Your study design constrains which variables you can measure —

which constrains which statistics are valid.

Module 2 — Sample Size & Sampling

🧭 Where are we? — Design ✅ → Sample Size → Variables → …

Why Sample Size Matters

  • Too small → underpowered, real effects missed (Type II error)
  • Too large → wasted resources, trivial effects become “significant”
  • Examiners will ask: “How did you arrive at this number?”
  • A justified sample size = a defensible Chapter 3

Single-Proportion Sample Size (Cochran)

\[n = \frac{Z^2 \, P(1-P)}{d^2}\]

Symbol Meaning
\(Z\) Standard normal value for confidence level (1.96 for 95%)
\(P\) Expected proportion (from prior literature/pilot)
\(d\) Margin of error (precision) you will accept

We are not deriving this — we are learning what each term forces you to justify.

Worked Example

Expected hypertension prevalence in an urban LGA = 30% (from prior study). You want 5% precision at 95% confidence.

Worked calculation

1.96² × 0.30 × 0.70 ÷ 0.05² → 323 participants

≈ 323 participants, before adjustments.

Walk through substitution live. Ask: “What happens to n if P were 50% instead of 30%?” (Answer: n increases — variance is maximized at P = 0.5.)

Adjustments You Will Likely Need

Finite population correction \[n_{adj} = \frac{n}{1 + (n-1)/N}\] Used when sampling frame (N) is small/known.

Non-response adjustment \[n_{final} = \frac{n}{1 - \text{(expected non-response \%)}}\]

Design effect (DEFF) \[n_{cluster} = n \times DEFF\] Applied when sampling is not simple random (e.g., cluster/multistage) — accounts for reduced precision from clustering.

Emphasize: DEFF is often the most forgotten adjustment in dissertations that use multistage sampling but calculate n as if SRS.

Comparing Two Groups (Conceptual)

For comparing two proportions or two means, sample size formulas add:

  • Expected difference you want to be able to detect (effect size)
  • Variability in each group
  • Desired power (usually 80–90%) in addition to confidence level
  • Larger detectable difference → smaller required sample

You will rarely hand-calculate these — but you must be able to defend every input you fed into G*Power/Stata/R.

Sampling Methods at a Glance

⚠️ Non-probability sampling limits generalizability — say so explicitly in your limitations.

Ask participants which method their proposed dissertation uses; multistage/cluster is common for community-based PH surveys in Nigeria.

Module 3 — Variables & Measurement Scales

🧭 Where are we? — Design ✅ → Sample Size ✅ → Variables → …

Two Fundamental Roles

🎯 Outcome / Dependent

The thing you are trying to explain or predict.

e.g., hypertension status, systolic BP

🔧 Exposure / Predictor / Independent

The thing you think influences the outcome.

e.g., smoking, age, BMI

Every dissertation objective should let you point at both.

Continuous vs Discrete vs Categorical

Type Definition Example
Continuous Any value on a range Age, BMI, SBP
Discrete Countable whole numbers Number of pregnancies
Categorical Named groups Sex, LGA, disease stage

Variables can be converted from one form to another

NOIR — The Measurement Scale Ladder

Scale Key idea Public-health examples
Nominal Categories with no inherent order Hypertension status (yes/no); vaccination status (vaccinated/unvaccinated); blood group (A/B/AB/O); LGA of residence; marital status; disease diagnosis; type of health facility
Ordinal Categories have a meaningful order, but gaps are not necessarily equal Cancer stage (I–IV); disease severity (mild/moderate/severe); educational attainment; socioeconomic class; Likert response (strongly disagree → strongly agree); nutritional status categories
Interval Equal intervals, but zero is arbitrary Temperature in °C; calendar year; date of diagnosis/date of birth
Ratio Equal intervals and a meaningful true zero Age; weight; height; systolic BP; CD4 count; monthly income; duration of illness; number of clinic visits

Common confusion: temperature in °C is interval (no true zero — 0°C isn’t “no temperature”); Kelvin would be ratio. Age/BMI/income all have a true zero and are ratio.

Tabular Data

Data is collected into a form of spreadsheet with rows and variables

Rows: horizontal (represents all measurements from a single unique observation)

Columns: vertical (a single attribute measured across all observations)

📌 The Golden Rule of Tidy Data

To keep data “tidy” and ready for analysis, every dataset must follow this strict structure:

Each variable must have its own column.

Each observation must have its own row.

Each value (individual cell) must contain a single measurement.

Common Data-Quality Problems Checklist

  • Missing values (and why they’re missing — random vs systematic)
  • Duplicate records/IDs
  • Impossible or out-of-range values
  • Inconsistent categorical coding across data collectors
  • Outliers — real vs data-entry error
  • BMI inconsistent with recorded height/weight
  • Unnecessary categorization of continuous variables (loses information/power)

Part B: Inferential Statistics

Population vs Sample

We never measure the population.

We measure a sample — and use it to make a careful, uncertain statement about the population.

What a P-value Actually Is

❌ “The probability the null hypothesis is true.”

✅ The p-value quantifies how incompatible the observed data are with the null model, under the assumptions of the test.

In plain terms: “If there really were no effect, how surprising would data like ours be?”

This is the single most important misconception to correct all workshop. Slow down here.

The 95% Confidence Interval

  • A range of plausible values for the true population effect, given your sample
  • “95% confidence” describes the procedure’s long-run reliability, not this specific interval
  • A CI that excludes the null value (0 for differences, 1 for ratios) aligns with statistical significance
  • Width tells you precision — wide CI = imprecise, even if “significant”

Statistical Power & Errors (Introductory)

H0 True H0 False
Reject H0 Type I error (α) Correct decision
Fail to reject H0 Correct decision Type II error (β)

Power = 1 − β → probability of detecting a real effect when one exists. This is why Module 2’s sample size mattered.

The Reusable Decision Sequence

  1. What is my research objective?
  2. What is my outcome variable — and its type?
  3. What is my explanatory/grouping variable — and its type?
  4. How many groups or measurements?
  5. Are observations independent or paired?
  6. Is the relevant distribution compatible with parametric assumptions?
  7. What effect estimate/test actually answers the question?

Memorize this sequence, not a giant table of tests.

Module 6 — Introduction to Regression

🧭 Where are we? — … → Bivariate ✅ → Regression → Interpretation

Why Regression? A Confounding Scenario

Crude analysis: smokers have much higher SBP than non-smokers. But smokers in this sample are also, on average, older.

Is the SBP difference really about smoking — or partly about age?

Regression lets us ask: “What is the effect of smoking, holding age constant?”

What determines your choice of regression analysis?

What variable type is your outcome variable of interest?

Continuous -> Linear regression

Dichotomous/Categorical -> Logistic regression

** How many variables are present?

Type of Analysis Number of Dependent Variables (Y) (The Outcome/Goal) Number of Independent Variables (X) (The Inputs/Predictors) Simple Real-World Example
Bivariate 1 1 You want to see if daily sodium intake (X) can predict a patient’s blood pressure (Y)
Multivariable 1 2 or more You want to see how sodium intake (X1), age (X2), and weight (X3) collectively predict a patient’s blood pressure (Y)

Bivariate → Confounding → Multivariable

Confounder = associated with both exposure and outcome, not on the causal pathway. Contrast briefly with mediator (on the pathway) and effect modifier (changes the effect size itself, not merely bias).

Binary Logistic Regression — Binary Outcome

Example: Hypertension (Yes/No) predicted by age, BMI, smoking

Logistic regression translates predictors into adjusted odds ratios (AORs).

🎂 Age    ⚖️ BMI    🚬 Smoking   →   🎯 Hypertension odds

Point out: exponentiating the logit coefficient converts it to an Odds Ratio — this single transformation confuses many residents.

Odds, Odds Ratios, COR vs AOR

  • Odds = P(event) / P(no event) — not the same as probability
  • Crude OR (COR) = unadjusted association from bivariate analysis
  • Adjusted OR (AOR) = association after controlling for confounders
  • Reference category must always be stated explicitly

🔮 Interpret Before We Reveal

AOR = 2.1 (95% CI: 1.3–3.4)

  1. Direction? → Positive association (AOR > 1)
  2. Does CI include 1 (the null)? → No → statistically significant at α = 0.05
  3. Magnitude? → Exposed group has ~2.1× the odds of the outcome, adjusting for covariates
  4. Causation? → No — this alone does not establish causality

Big Idea

Regression adjusts estimates.

It does not rescue a poorly designed study.

Module 7 — Dissertation Pitfalls, Integration & Closing

🧭 Where are we? — … → Regression ✅ → Integration & Reporting

Common Dissertation Pitfalls

  • Objective ↔︎ test mismatch
  • Unjustified categorization of continuous variables
  • Incorrect denominators
  • Reporting only p-values
  • Missing effect estimates / CIs
  • Vague description of sampling
  • Analyzing before cleaning
  • Parametric vs non-parametric testing pitfall
  • Regression variables with no conceptual rationale
  • OR/AOR misinterpreted as relative risk

🔍 Spot the Problem — Mock Table

Variable p-value
Age 0.041237
Smoking (n = 61/300, n = 45/442) 0.002891029

Problems: only p-values (no estimates/CIs), excessive decimal places, inconsistent denominators for smoking (300 vs 442 — missing data unexplained).

Five Rules to Take Home

  1. Design analysis plan from the start (conception of project) - keep your research objective in mind
  2. Know your variables
  3. Clean and describe before testing
  4. Report estimates and uncertainty — not p-values alone
  5. Use regression thoughtfully, not automatically
